# ☕ Aurora Café

Um site desenvolvido para uma cafeteria fictícia, com uma interface moderna, responsiva e intuitiva. O projeto apresenta os produtos da cafeteria, permite filtrar as opções do cardápio e adicionar itens a um pedido de forma interativa.

## 📌 Sobre o projeto

O **Aurora Café** foi criado como parte da atividade prática de desenvolvimento de um site criativo, com o objetivo de aplicar conceitos de HTML, CSS e JavaScript na construção de uma página funcional e visualmente organizada.

O site possui uma identidade visual inspirada em cafeterias modernas, com cores aconchegantes, cards de produtos e adaptação para diferentes tamanhos de tela.

## ✨ Funcionalidades

- **Navegação:** menu com links para as principais seções do site.
- **Apresentação:** seção inicial com título, descrição e botão de ação.
- **Cardápio:** exibição de cafés e doces em cards.
- **Filtro de produtos:** permite visualizar todos os produtos ou filtrar por categoria.
- **Pedido interativo:** permite adicionar produtos ao pedido e visualizar o valor total.
- **Limpar pedido:** opção para remover os itens adicionados.
- **Menu responsivo:** navegação adaptada para dispositivos móveis.
- **Notificações:** mensagens exibidas ao realizar determinadas ações.
- **Ano automático:** o ano do rodapé é atualizado por JavaScript.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, responsividade e reutilização de estilos.
- **JavaScript:** funcionalidades interativas e manipulação do DOM.
- **Google Fonts:** tipografia utilizada na interface.
- **Unsplash:** imagens utilizadas na apresentação dos produtos.

## 📚 Conceitos aplicados

### 1. Variáveis CSS

Foram utilizadas variáveis CSS para centralizar valores de cores, fontes, espaçamentos e outros estilos, facilitando a manutenção e a personalização da interface.

Exemplo:

```css
:root {
    --cor-principal: #...;
    --cor-fundo: #...;
    --espacamento: ...;
}
```

### 2. Classes utilitárias

Foram criadas classes reutilizáveis para evitar a repetição desnecessária de estilos em diferentes elementos.

### 3. Estilos compartilhados

O projeto utiliza classes-base compartilhadas entre componentes, permitindo reaproveitar propriedades de estilo e manter a consistência visual.

### 4. Funções JavaScript

Foram implementadas funções para atualizar o pedido, calcular o valor total, formatar preços, filtrar produtos e exibir notificações.

### 5. Responsividade

O layout utiliza media queries para adaptar a apresentação dos elementos a diferentes larguras de tela, incluindo computadores, tablets e celulares.

## 🚀 Como executar

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto localmente.
